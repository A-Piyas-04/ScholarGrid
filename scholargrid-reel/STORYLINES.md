# ScholarGrid marketing reel — storylines

**Assumptions:** ~40s · 9:16 (1080×1920) · narrated (Kokoro-82M open-source TTS) · music bed if a free track is available else VO + SFX · no HeyGen avatar · motion-graphics landscape (no invented product UI screenshots).

## Recommended: A — The Map Was Always There
**Device:** life before/after + kinetic type · **Form:** object-to-object chain (scattered paper cards → constellation landscape → punch into clusters → end mark)

Viewer feels the frustration of keyword lottery, then watches chaos lock into a readable research terrain. First 2s: giant “STOP SEARCHING” over flying arXiv-title cards. Beats: hook → chaos → status-quo dump → map builds → drop-on-map → trends/leads → callback → end card. Look: deep ink `#071018`, cyan `#3EE0C4`, paper white type, Space Mono + Outfit. Sound: confident mid voice, soft whooshes on map coalesces, bed under VO at ~0.14.

## B — One Query, One Neighbourhood
**Device:** one object across apps · **Form:** endless zoom into a single search result that becomes a region

Starts mid-search; the result card zooms until it is a labelled cluster with sparse leads around it. Stronger for product demo, weaker as cold-hook social.

## C — Sparse Is the Signal
**Device:** a number lands · **Form:** cut-on-beat type + sparse-dot reveal

Leads with “investigation leads” as the hero idea. Niche-credible, less mass-retention than A.
